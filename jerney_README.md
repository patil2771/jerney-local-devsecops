## DevOps Portfolio Implementation

This repository uses the Jerney application originally created by
[Veeramalla](https://github.com/iam-veeramalla/Jerney).

The application is being used as the workload for my DevOps/DevSecOps portfolio project.

My implementation focuses on:

- Docker and Docker Compose
- PostgreSQL persistence
- Container health checks
- Kubernetes
- Helm
- CI/CD with GitHub Actions
- Security scanning
- GitOps
- Monitoring and troubleshooting
